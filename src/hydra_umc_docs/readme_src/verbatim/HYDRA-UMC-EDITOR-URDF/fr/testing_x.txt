### Tests Automatisés

```bash
pip install -r requirements-dev.txt
python -m pytest tests/ -q
```

Note : la logique pure de cette application (analyse/export URDF, validation de faisabilité DOF, cinématique directe, estimation d'inertie, résolution des références de maillage, récupération GitHub, i18n) n'avait aucune couverture de tests automatisés. Corrigé : {tests} vrais tests répartis sur 15 modules de test, dont tous sauf quelques-uns évitent PySide6/PyOpenGL (ces quelques-uns ouvrent sans écran l'écran DOF et le panneau de validation physique et sont ignorés là où Qt ne peut pas démarrer) - `requirements-dev.txt` installe uniquement ce dont `tests/` a réellement besoin (`numpy` + `pytest`), donc la suite s'exécute sans écran ni plugin de plateforme Qt. Plusieurs tests sont des régressions explicites pour des bugs déjà trouvés et corrigés auparavant et documentés directement dans le code source (la protection contre la boucle infinie sur un vrai cycle de `render/kinematics.py`, le conditionnement `had_scheme` de `source/scan.py`, la vérification de masse négative de `urdf/dof.py`) - une future modification ne peut plus réintroduire silencieusement l'un d'eux sans faire échouer un test. La CI (`.github/workflows/ci.yml`) exécute la même commande à chaque push.
