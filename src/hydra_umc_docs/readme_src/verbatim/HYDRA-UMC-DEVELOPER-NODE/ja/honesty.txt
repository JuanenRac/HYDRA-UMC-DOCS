**正直さの確認 - 現在実際に動くもの：** 証拠の取り込み（署名、nonce、チェックサム、秘密情報の確認）、ダイジェストに結び付いた承認を持つ実行可能な再現ケース、上限付きのチェックアウトキャッシュ、状態文書、`ecosystem-ci` プラグイン、8 言語のテキストは実装済みでテスト済みです（自動テスト {tests} 件、ローカルの git リポジトリとローカルのプロセスで実行）。ノードは実際の開発ホストでは動作しておらず、レシピは許可リストと最小限の環境以上には隔離されておらず、キューから自動で作業を取り出すものはありません。出荷済みの内容は `CHANGELOG.md` を参照してください。

> **安全性とセキュリティの現状:** このエコシステムは認証された安全システムではありません。ハードウェアの E-STOP 経路、ファームウェアが強制する制限やインターロック、検証済みの動作コマンドはまだありません。ファームウェアイメージは CRC-32 と Ed25519 署名で検査し、リリースビルドは公開済みの開発用鍵を拒否します(リレーの先のツールヘッドと拡張ボードは引き続き URTC のブートローダーを使い、署名ではなく共有鍵の HMAC-SHA256 を使います)。TLS と相互 TLS は任意で、既定では無効です。独自基板はまだ実装も試験もされていません。ここに書かれた内容を人の安全のために頼る前に、[セキュリティベースライン](https://github.com/JuanenRac/HYDRA-UMC-DOCS/blob/main/docs/SECURITY_BASELINE.md)と[脅威モデル](https://github.com/JuanenRac/HYDRA-UMC-DOCS/blob/main/docs/THREAT_MODEL.md)をお読みください。
